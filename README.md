# ВІККОН — сайт vikkon.com

Статичный сайт компании «ВІККОН» (купівля та продаж металобрухту, Дніпро).
Семантический HTML5 без зависимостей, адаптивная вёрстка.

Дизайн: тёмная шапка и hero, крупная типографика, карточки, тёмный блок
с телефонами и тёмный подвал — в фирменной синей палитре «ВІККОН».
Тексты, цены, фотографии и контакты — с оригинального сайта.

## Структура

```
index.html                         Головна (UA — основной язык)
ru/buy_scrap/index.html            Купівля брухту (прайс)
ru/scrap_implementation/index.html Реалізація брухту
ru/contacts/index.html             Контакти
rus/…                              русская версия тех же четырёх страниц
assets/css/style.css               стили (переменные палитры — в :root)
assets/js/site.js                  меню, шапка/паттерн при прокрутке, просмотр картинок, «Вгору»
assets/js/slideshow.js             слайдшоу на главной
assets/fonts/                      шрифт Manrope (самохостинг, woff2)
assets/img/theme/                  логотип, иконки, награды, metal-pattern.jpg (фон)
assets/img/banners/                слайды slide-1…7.jpg
assets/img/content/                картинки контента и карты проезда
docs/download/kp_11_01_2013.doc    прайс для скачивания
```

URL украинских страниц те же, что на старом сайте (`/ru/buy_scrap/` и т.д. —
исторические адреса, язык там украинский). Русская версия лежит в `/rus/`.
Переключатель UA / RU в шапке ведёт на ту же страницу на другом языке.

Шапка, блок с телефонами и подвал повторяются на всех страницах, а каждая
страница есть в двух языках — при правке текста, цен или контактов меняйте
обе версии.

## Локальный просмотр

Ссылки ведут на папки (`ru/contacts/`), поэтому открывайте через локальный сервер:

```sh
python3 -m http.server 8000
# http://localhost:8000/
```
