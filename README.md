# ВІККОН

«ВІККОН» — компания из Днепра, которая с 2006 года покупает, перерабатывает и продаёт лом чёрных и цветных металлов. Также компания вывозит лом и выполняет демонтаж металлоконструкций. Деятельность по приёму и переработке металлолома лицензирована.

Этот сайт — прототип будущего сайта компании.
