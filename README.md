# ВІККОН — сайт vikkon.com

Статичный сайт компании «ВІККОН» (купівля та продаж металобрухту, Дніпро).
Семантический HTML5 без зависимостей, адаптивная вёрстка.

Дизайн: тёмная шапка и hero, крупная типографика, карточки, тёмный блок
с телефонами и тёмный подвал — в фирменной синей палитре «ВІККОН».
Тексты, цены, фотографии и контакты — с оригинального сайта.

## Структура

Сайт одностраничный: меню в шапке прокручивает к блокам на этой же странице
(«Головна», «Ціни» `#prices`, «Про компанію» `#about`, «Контакти» `#contacts`).
Шапка с кнопкой «Зателефонувати» всегда остаётся на экране.

```
index.html                         вся страница (UA — основной язык)
rus/index.html                     та же страница на русском
assets/css/style.css               стили (переменные палитры — в :root)
assets/js/site.js                  меню, шапка при прокрутке, подсветка раздела, просмотр картинок
assets/js/slideshow.js             слайдшоу в первом экране
assets/fonts/                      шрифт Manrope (самохостинг, woff2)
assets/img/theme/                  логотип, иконки, награды, metal-pattern.jpg (фон)
assets/img/banners/                слайды slide-1…7.jpg
assets/img/content/                карты проезда и картинки старых страниц
docs/download/kp_11_01_2013.doc    прайс для скачивания
ru/…, rus/buy_scrap/ и т.д.        старые отдельные страницы — оставлены, с главной на них ссылок нет
```

Кнопка языка в шапке (RU / UA) открывает эту же страницу на другом языке.
При правке текста, цен или контактов меняйте обе версии: `index.html` и `rus/index.html`.

## Локальный просмотр

Русская версия лежит в папке `rus/`, поэтому открывайте через локальный сервер:

```sh
python3 -m http.server 8000
# http://localhost:8000/
```
