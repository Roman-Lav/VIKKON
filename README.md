# ВІККОН — сайт vikkon.com

Статичный сайт компании «ВІККОН» (купівля та продаж металобрухту, Дніпро),
переписанный с XHTML 1.0 + jQuery 1.4 на семантический HTML5 без зависимостей.
Внешний вид сохранён один в один.

## Структура

```
index.html                         Головна
ru/buy_scrap/index.html            Купівля брухту (прайс)
ru/scrap_implementation/index.html Реалізація брухту
ru/contacts/index.html             Контакти
assets/css/style.css               стили (перенесены из themes/vikkon/res/style.css)
assets/js/slideshow.js             слайдшоу баннеров (чистый JS вместо jQuery)
assets/img/theme/                  фон, логотип, блоки сайдбара, награды, иконки
assets/img/banners/                баннеры слайдшоу
assets/img/content/                картинки контента и карты проезда
docs/download/kp_11_01_2013.doc    прайс для скачивания
```

URL страниц те же, что на старом сайте (`/ru/buy_scrap/` и т.д.).

## Локальный просмотр

Ссылки ведут на папки (`ru/contacts/`), поэтому открывайте через локальный сервер:

```sh
python3 -m http.server 8000
# http://localhost:8000/
```

## Доступность (скринридеры)

- Ориентиры: `header`, `nav` (с `aria-label`), `main`, `article`, `aside`, `footer`.
- Ссылка «Перейти до змісту» для клавиатуры; видимый фокус только при навигации с клавиатуры.
- Текущая страница в меню помечена `aria-current="page"`.
- Прайс — настоящая таблица с `caption`, заголовками строк и групп.
- Декоративное слайдшоу скрыто от скринридеров и не крутится при `prefers-reduced-motion`.
- Награды в сайдбаре (картинка с текстом) продублированы скрытым текстом.
- Телефоны и e-mail — кликабельные ссылки `tel:` / `mailto:`.

## Обновление цен

Таблица цен — в `ru/buy_scrap/index.html`. При изменении обновите дату в двух
элементах `<time datetime="...">` на этой странице.
